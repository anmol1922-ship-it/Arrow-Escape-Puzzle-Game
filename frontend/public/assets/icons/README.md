# Arrow Escape Icons

Use one consistent, minimal icon family for navigation and utility controls.
Icons must have a visible or programmatic accessible name, a 44 by 44 pixel
interactive target, and a non-color state cue when state matters.

Directional arrows use the game arrow renderer, not a text glyph as their
primary visual. Prefer CSS/SVG geometry for game-specific shapes and keep
decorative assets separate from controls.
